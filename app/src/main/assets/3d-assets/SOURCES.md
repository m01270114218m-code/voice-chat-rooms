# Farah Chat asset sources

## 3D models, textures and HDRIs
Poly Haven is the primary source for production 3D assets in this project. Its published assets are CC0 and may be used commercially.

Source: https://polyhaven.com/
License: CC0

## SVGA format
SVGA 2.x is a binary animation format using Protocol Buffers and zlib compression. Runtime animation files must be real .svga files; renaming SVG/PNG files is not valid.

Format specification: https://github.com/svga/SVGA-Format

## Integration rule
Only assets with a clear license are admitted to the app asset pack. Each imported asset should retain its source URL and license in this file or a per-asset manifest entry.
