# Farah Chat 3D Asset Pack

This directory defines the complete 3D asset pack for the Farah Chat Android app.

Planned assets:
- room environments
- avatars and avatar accessories
- seating/platform props
- furniture and decorative props
- UI 3D icons
- room backgrounds and lighting presets

Recommended production formats: GLB/GLTF for runtime 3D, PNG/WebP for baked textures, and SVG/VectorDrawable for UI icons.

Asset naming convention: `farah_<category>_<name>_v001`.
